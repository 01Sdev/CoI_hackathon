2026-10-31 저녁 기준. 마감 2026-11-01 12:00 KST.

## 무엇을 만드나
1인칭 카메라와 그 위에서 도는 앱(플러그인) 사이에 들어가는 웹 런타임이다. 앱은 원본 화면 대신 필요한 조각 한 장만 받는다. 찍힌 사람의 얼굴은 가려서 보내고, 불확실하면 보내지 않는다. 화면이 해야 할 일은 하나다. "앱이 무엇을 받았는지"를 착용자와 찍히는 사람이 눈으로 확인하게 하는 것이다.

## 화면 4개
| 화면 | 기기 | 배치 |
| --- | --- | --- |
| 휴대폰 | 심사위원 폰 | 후면 카메라 전체 화면 + 가운데 HUD + 하단 시트에 증명 로그 |
| 데스크톱 | 발표 노트북 | 왼쪽 카메라와 HUD, 오른쪽 탭 4개(로그, 확인 화면, 매니페스트, 처리량) |
| 글래스 `/hud` | Ray-Ban Display 웹앱 시뮬레이터 | HUD만, 검은 배경, D-pad 조작, 입력은 녹화 영상 |
| 바깥 표시 `/outward` | 발표 노트북 두 번째 창 | 찍히는 사람을 향한 화면. "지금 당신의 얼굴을 본 앱: N개"를 화면 높이 30% 이상 크기로 |

휴대폰과 데스크톱은 폭 768px로 자동 선택하고, 수동으로도 바꿀 수 있다.

## HUD 규칙 (PRD)
- **600×600 기준, 요소는 5개 이내:** 장면, 입력, 대상 위치, 카운터, 결과.
- **주인공은 카운터 "현재 앱에 반영된 사람 수: 0명"이다.** 팀 결정으로 "얼굴"이 아니라 "사람" 문구를 유지한다.
- **크기:** 검은 배경(가산형 디스플레이에서 투명)에 밝은 글자. 본문 24px 이상, 카운터 40px 이상이다. 600px보다 좁은 휴대폰에서는 비례 축소한다(추천, 결정판 14번).
- **색은 의미에만 쓴다.**
  - 초록: 아무도 넘어가지 않음
  - 주황: 비교 모드에서 얼굴이 넘어감
  - 빨강: 차단 이벤트(변조 플러그인)
- **"보호 중" 상태 표시는 카운터와 따로 둔다.** 비교 모드를 끄면 보호 표시는 바로 바뀌고, 카운터는 10초 안에 0으로 내려간다.

## 전달 신호
- **기본 신호:** 전달될 때마다 HUD 테두리가 300ms 밝아진다.
- **보조 신호:** 효과음 120ms와 Android 진동이다. iPhone은 무음 모드에서 소리가 나지 않는 것을 실측으로 확인했다.
- **보류:** 소리 없이 하단 줄에 "보류"만 띄운다.
- **시작 버튼은 유지한다.** iPhone은 사용자 조작이 있어야 소리를 켤 수 있고, 카메라 권한 요청도 이 버튼에서 시작한다.

## 아직 정해지지 않은 것 (디자인에 영향)
- **32번 비교 모드 띠 색.** 추천은 주황이다. 빨강은 "차단" 전용이라 겹친다.
- **33번 `/hud` D-pad.** 추천: 좌우는 최근 전달물 선택, 선택은 상세, 뒤로는 닫기.
- **N3 무음 모드 대비.** 테두리 점멸 + "전달됨" 표시를 기본으로 한다.
- **N5 사람 장면 로그 표시 여부.**
- **N9 F19 기업 서버 재검사.** 토글로 둘지, 비활성 "미구현" 안내로 둘지.
- **"발표자 화면 전용" 컨트롤 묶음.** 비교 모드, 새 세션 시작, 전달 일시 정지(검토 중)가 들어간다.

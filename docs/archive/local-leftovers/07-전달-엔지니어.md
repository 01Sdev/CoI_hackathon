## 꼭 지킬 계약 (02-SSRD 요약)
- **메시지:** 호스트 → 플러그인 `init`(매니페스트, `apiBase`, 코드), `delivery`(Blob, 장면 분류 `scene`, 물체 라벨 `objectLabel`). 플러그인 → 호스트 `ready`, `ack`(받은 Blob의 SHA-256), `result`, `violation`. 기대 해시는 메시지에 싣지 않는다.
- **전달:** Blob을 그대로 보낸다(transfer 없음). Delivery는 `prepared` → `dispatched`/`failed`이고, `dispatched`만 전달로 센다.
- **전환 공통 절차:** 매니페스트 적용, 비교 모드 켜기·끄기, 입력 전환, 새 세션은 모두 다음 순서를 따른다. 전달 게이트 닫기 → 진행 중 작업 버림 → 옛 iframe 종료 → 새 iframe(`runtimeId` 새로) → 3초 안에 `ready`면 게이트 열기, 아니면 플러그인 정지. 옛 권한으로 되돌아가지 않는다.
- **2단계 순서:**
  1. 포착한 프레임에서 대상과 사람을 다시 검출한다.
  2. 줄이기 전의 조각에서 얼굴을 검출한다.
  3. 사람 박스마다 얼굴이 대응되는지 판단한다.
  4. 안전 검사에는 5%·60% 필터를 쓰지 않는다.
  5. `maxSide`로 줄이고 JPEG로 만든다.
  6. 출구 재검사를 한다(P0). 얼굴이 남았거나 검사가 실패하면 보류한다.
- **CSP:** iframe마다 새 nonce, `worker-src blob:`, `connect-src`는 매니페스트 `network`만 둔다. 호스트 페이지에는 `script-src` CSP를 두지 않는다. Worker를 못 만들면 그 플러그인은 켜지 않는다.
- **매니페스트 7개 필드:** `purpose`, `scenes`, `region`(`"target"`만), `maxSide` 32–512(기본 256), `quality` 0.5–0.92(기본 0.8), `maxPerMinute` 1–30(기본 6), `network`(https origin). 모르는 필드가 있으면 전체 거부한다.
- **`/api/calorie`:** `POST image/jpeg` 본문을 그대로 받고 `x-label`에 `objectLabel`을 담는다.
  - 성공하면 200과 결과 한 줄을 돌려준다. 받은 바이트와 해시는 `X-LensGate-Body-Bytes`, `X-LensGate-Body-SHA256` 헤더로 알려 준다.
  - 오류 코드는 413, 415, 429, 502이고, 플러그인 쪽 시간 제한은 3초다. 실패하면 고정표로 대체한다.
  - 비용 상한은 Anthropic 지출 한도로 건다. 모델은 `claude-haiku-5-5`이고 키는 B가 서버 환경 변수로 관리한다.
- **카운터:** 화면 로그(최근 100건)와 따로 쌓는 숫자 기록에서 센다.
  - M은 최근 10초 전달본에서 출구 재검사로 잰 얼굴 수의 최댓값이다.
  - 비교 모드를 끄면 보호 표시는 바로 바뀌고, 카운터는 10초 안에 0이 된다.
- **비교 모드:** 칼로리 iframe을 `connect-src 'none'`, `apiBase: null`로 다시 만든다. 결과는 고정표를 쓰고, 원본은 브라우저 밖으로 나가지 않는다.

2. V1 MediaPipe, V2 얼굴 모델, V8 녹화 입력, V9 Android 격리를 확인한다.
3. V11 배포본 통합 격리·전환 시험을 한다.
4. 나머지 UX·발표 확인을 한다. V5 칼로리 AI는 병렬로 진행하되 다른 작업의 선행 조건이 아니다.

- 격리: blob Worker, nonce CSP, 차단 동작

- 카메라: 720×1280, 포착 평균 29ms
- 해시: 순수 JS 경로 match·mismatch·timeout
- 위험 하나: 첫 추론까지 14.1초·11.4초로 10초 목표를 넘었다

## 2. 실기기로 확인할 것 (iPhone Safari 실측처럼)

### 2.1 이미 확인한 것

iPhone 16 Pro(iOS 27.2) Safari에서 따로 만든 HTTPS 재현 페이지로 확인했다(S1~S10, S12). 확인한 것은 다음과 같다.
- origin `null` iframe에서 blob Worker 생성
- nonce CSP와 호스트·iframe CSP 교집합
- Worker의 금지된 요청 차단
- srcdoc 최초 `load` 1회
- Worker 안 `crypto.subtle`
- `quality`에 따른 JPEG 크기 변화
- 후면 카메라, 인라인 재생, 오디오 활성화
- 진동 API 없음
- `Origin: null` CORS

CSP 위반 이벤트는 관측되지 않았다(S4). 그래서 위반 로그는 플러그인 자기 보고로 남긴다. 상세는 02-SSRD §3 "검증 근거"에 있다.

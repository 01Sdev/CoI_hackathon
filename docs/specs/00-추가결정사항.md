## 2. 발표에서 하지 말 것 (확인된 결정)

- **촬영 LED 얘기:** 외부 앱이 스트리밍할 때 LED가 켜지는지 확인되지 않았다.
- **"몇 시간이고 켤 수 있다":** 시간 제한이 문서에 "명시되지 않았을" 뿐이다. 배터리·발열 한계는 모른다.
- **"배터리 몇 % 절감":** 웹에서는 잴 수 없다. 처리량 패널의 모델 호출 횟수로만 말한다.
- **카드번호 질문에 대한 답:** framelet은 인식으로 막는 게 아니라 목적 영역만 보내는 최소화로 막는다. 카드가 잘라낸 조각 안에 들어가면 같이 넘어간다. 카드가 남의 것이면 문제 2가 얼굴에서 민감정보 전반으로 넓어지는 사례가 된다.

## 3. iOS 트랙 현황 (보너스 · 슬라이드 자산)

- Meta 개발자 센터에 `inthon_hackathon` 프로젝트 생성. 한국 계정으로 등록됨.
- Configuration 칸(Team ID, Bundle ID, Universal link)은 실제 기기 연결 때만 필요해서 비워 둠.
- 맥 환경: Xcode 27.2, iOS 27.0 시뮬레이터, `meta-wearables-dat-ios` 클론, CameraAccess 샘플, Claude Code `mwdat-ios` 플러그인 설치 완료.
- 휴대폰 빌드 오류와 해결책:
  - PLA 오류 → developer.apple.com에서 약관 동의
  - Hotspot / Access Wi-Fi 권한 오류 → 무료 계정이면 두 권한 삭제, Bundle ID를 고유한 값으로 변경
- **웹을 택한 근거 (SRD에 넣는다):** iOS 앱은 심사위원 폰에 배포하기가 사실상 불가능하다. 무료 계정은 내 기기에만 설치되고 7일이면 만료된다. TestFlight는 베타 심사가 필요하고, Ad-hoc 배포는 기기마다 UDID를 받아야 한다.

## 4. 구현 결정 (`AGENTS.md`) → SRS·SDD

| 영역 | 내용 |
|---|---|
| 스택 | Vite + React 18 + TS strict, zustand, `@mediapipe/tasks-vision`, Vercel 함수(SDK 없이 `fetch`), UI 라이브러리 금지 |
| 배포 자산 | 모델과 WASM을 CDN이 아닌 `/public`에 두고, `postinstall`에서 WASM 복사. `vercel.json`에 `/hud` 경로 재작성 |
| 저장소 소유 | 트랙별 디렉터리: A는 `input/vision/broker`, B는 `plugins/api`, C는 `ui/proof`. `core/`는 합의 없이 수정 금지 |
| 메시지 규약 | 호스트→플러그인: `init`, `delivery`. 플러그인→호스트: `ready`, `ack`, `result`, `violation`. `event.source`를 검증하고, `ready`를 받은 뒤에만 전달. 격리된 프레임의 origin이 `"null"`이라 API 주소는 `init`의 `apiBase`로 넘김 |
| 매니페스트 | 필드는 7개: `purpose`(확인 화면 표시, 40자 이하), `scenes`, `region`(`"target"`만), `maxSide` 32–512, `quality` 0.5–0.92, `maxPerMinute` 1–30(기본 6), `network`(https origin만). 모르는 필드는 전체 거부. 주소는 `$ORIGIN`으로 치환. 잘못된 JSON은 기존 값 유지, 유효한 변경은 iframe 재생성(실패하면 플러그인 정지, 이전 권한으로 복귀하지 않음). `region`·`purpose`·기본값·실패 처리는 2026-10-31 추가 |
| 플러그인 SDK | `framelet.onInit / onDelivery / result / reportViolation`(시그니처와 규칙은 02-SSRD "플러그인 SDK", 타입은 `src/core/sdk.ts`). 전달을 받으면 자동으로 해시 계산 후 응답. `crypto.subtle`이 없으면 순수 JS SHA-256. 차단 기록에는 "플러그인 내부 보고"라고 표기 |
| 로그 운영 | 최근 100건만 유지, 밀려난 썸네일은 해제. 같은 사유의 "전달 안 함" 로그는 10초에 1번만 |
| 판정 세부 | 음식 라벨 12종 목록. 사람은 프레임의 5% 이상일 때만 대상. 음식이 사람보다 우선. 프레임 콜백이 없으면 `setInterval`, GPU 실패 시 CPU |
| 입력 세부 | `<video>`에 `playsInline muted autoplay` 필수. 카메라 거부 시 녹화 영상으로 자동 전환. 화면 폭 768px 미만이면 후면 카메라, `/hud`는 녹화 영상 |
| 비밀값 | API 키는 클라이언트에 두지 않음. 빌드 결과물 `dist`에서 키 문자열을 grep으로 확인 |

## 5. API 명세 (`AGENTS.md`) → SRS 외부 인터페이스

- `POST /api/calorie`: 본문은 `image/jpeg` 바이트, 선택 헤더 `x-label`.
  - 600KB 초과 413, 이미지가 아니면 415.
  - CORS `*`, `OPTIONS`에는 204.
  - 2.2초 안에 답이 없으면 502.
  - 이미지는 저장하지 않음.
- 환경 변수: `ANTHROPIC_API_KEY`, `CALORIE_MODEL`(기본값 `claude-haiku-5-5`).
- 응답 형식: `<음식> 약 <숫자>kcal`, 음식이 아니면 `음식 아님`.
- API 실패 시 고정표(kcal): 바나나 105, 사과 95, 오렌지 62, 도넛 250, 피자 285, 샌드위치 300, 케이크 350, 핫도그 290, 브로콜리 30, 당근 25.

## ERD 축약 방향

영구 저장소(DB)는 없고 데이터는 모두 브라우저 메모리에만 있다. ERD는 메모리 데이터 모델로 6~7개 엔티티면 충분하다. 제안 묶음: Session, Plugin(Manifest), SceneSnapshot, Detection, Delivery, LogEntry, Counter.

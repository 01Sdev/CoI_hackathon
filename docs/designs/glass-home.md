# 글래스 AR 홈 흐름

상태: 1차 구현(2026-11-01, `track-c/glass-home`). 코드는 `src/ui/GlassFlow.tsx`, `src/ui/glassHome.ts`, `src/ui/GlassIcons.tsx`, `src/ui/glass-home.css`다.

## 사용자 요구(원문 요지, 2026-11-01)

- 광각 효과로 "실제 스마트 글래스는 이런 시야를 가진다"를 간접적으로 보여 주고, 그 글래스에서 볼 화면 구성을 아이폰 사파리에서 볼 수 있게 한다.
- 사이트에 들어가면 바로 플러그인으로 가지 않는다.
  1. 카메라 권한을 먼저 받는다.
  2. AR 형태로 홈 화면을 띄운다. 애플 비전 프로 홈 배치(4/5/4)를 따른다. 나머지 자리는 YouTube 같은 기성 앱이고, 정가운데(둘째 줄 3번째)는 framelet(5×5 격자 마크)이다. 누르면 눌리는 애니메이션 뒤에 앱이 열린다.
  3. framelet 앱은 바로 플러그인을 시작하지 않는다. 앱 목록(설계 P2)을 줄인 버튼 넷(칼로리, 코디 스캔, 변조 시험, "+ 추가...")을 AR로 띄우고, 그 바깥을 #44 흰 틀이 사방으로 감싼다. 칼로리나 코디 스캔을 누르면 그때 플러그인이 실행된다.
  4. 플러그인 UI는 플랫폼 틀 밖에 있어도 된다(금빛 상태창, 코디 스캔 답 패널과 같은 규칙).
- 참고 그림: Android XR 홈(카페, 원형 아이콘 2줄), Vision Pro 홈(거실, 원형 아이콘 4/5/4). 카메라 공간 위에 원형 아이콘과 그 아래 작은 흰 글자가 뜬다.

## 기본값(허브, 사용자가 바꾸면 따른다)

| 항목 | 정한 값 |
| --- | --- |
| 배경 | 후면 카메라 실시간 영상(A `mountPreview`). 광각 휘어짐은 A가 입력 단계에서 넣는다(별도 PR). C는 `<video>`·원본 픽셀을 만지지 않는다. |
| 글래스 느낌 | 가장자리를 살짝 어둡게 하는 비네트 + 렌즈 테두리처럼 둥근 시야 가장자리. 시야각 숫자는 적지 않는다. |
| 카메라 권한 | 첫 화면은 질문 "카메라 권한을 허용할까요?"와 버튼 "허용"(주 버튼)·"허용 안 함"뿐이다(사용자 요청 2026-11-01: 문구 없이 담백하게). "허용"은 소리 잠금 해제와 `selectInput` 의도, "허용 안 함"은 녹화 영상(`selectInput('video')`)으로 홈에 간다. 브라우저 권한 창에서 거부·실패하면 A의 녹화 영상 대체를 그대로 탄다. |
| 카메라 고르기 | 터치 기기(아이폰 가로 874px 포함)는 후면, 아니면 웹캠(`cameraFor`). 폭만 보면 아이폰 가로가 데스크톱으로 잡혀 앞 카메라가 켜진다. |
| 홈 아이콘 | 원형, 아래 작은 흰 글자와 그림자. 기성 앱 12개는 공식 로고 파일 없이 단순 SVG(TV·음악·YouTube·설정·Safari·사진·메모·지도·메일·메시지·캘린더·날씨). |
| 누르기 | 0.92배로 눌렸다 돌아온 뒤(160ms) 연다. 기성 앱은 "시연에서는 열리지 않아요" 알림만. framelet은 아이콘 자리에서 커지며 런처가 열린다. 움직임 줄이기면 애니메이션 없이 바로 바꾼다. |
| 런처 | 버튼 넷. 가로는 한 줄, 세로는 2×2. 바깥 사방에 #44 흰 틀(1px 선, ㄱ자 손잡이, 변 가운데 막대)을 장식으로 두른다(끌 수 없음). 아이콘은 `docs/designs/app-screens/Apps.dc.html` SVG, "추가..."는 회색 반투명 원에 +. |
| 런처의 사람 수 | 뺐다. 런처에서는 아무 앱도 돌지 않아 넘어가는 사람이 없다. 앱 화면의 흰 틀에는 그대로 있다(FR-035). |
| 플러그인 실행 | 런처에서 고른 앱 하나만 켜고(`setPluginEnabled`), 런처·홈으로 돌아오면 끈다. 연결·규약 보기는 안 B 그대로(승인 화면 없음, 규약 보기는 `?tools`의 앱 관리). |
| 변조 시험 | 고르면 변조 플러그인만 켜고, 앱 화면 아래에 "변조 시험 · N번 막음 · 마지막 사유" 카드를 띄운다(글래스 흐름에는 기록 화면이 없어서). |
| 추가... | 눌림 애니메이션과 "앱 추가는 다음 단계예요" 알림만. |
| 돌아가기 | 화면 아래 가운데 홈 알약(비전 프로 디지털 크라운 역할). 앱 → 런처, 런처 → 홈. 홈에서는 숨긴다. 보이는 알약은 56×6px, 누를 자리는 96×44px. |
| 아이폰 사파리 | 가로 기준, 세로도 깨지지 않게. `100dvh`, safe-area inset, 누를 곳 44px 이상. |

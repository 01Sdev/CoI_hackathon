# 설계: famelet 디자인 시스템 (다크·라이트)

상태: 사용자 검토 대기(이 PR 머지 = 승인) · 2026-10-31 · 근거: 팀 시안 "LensGate OS" Dark·Light 두 장, `docs/specs/PRD.md` "HUD·화면 요구사항"과 F6·F8·F9·F12·F15·F17·F20 · 코드: `src/ui/theme.css`, `src/ui/theme.ts` · 미리보기: `npm run dev` 후 `/dev/design.html`(프로덕션 빌드에 들어가지 않음)

## 1. 원칙

시안을 따른다. 바꾼 곳은 셋뿐이다. 명세와 부딪히는 곳, 측정해 보니 읽기 어려운 곳, 시안에 없어서 새로 정한 곳이다. 각각 §4·§5·§6에 이유를 적었다.

- 실제 시야 위에 떠 있는 유리. 흐림 22px, 외곽선 1.5px.
- 색은 의미에만 쓴다(PRD HUD 규칙). 초록 = 아무도 넘어가지 않음, 주황 = 비교 모드·노출, 빨강 = 차단, 보류 = 색 없음.
- 색과 글자를 항상 함께 쓴다(시안 "상태 캡슐 · 색과 글자 함께").
- 기본은 다크다(시안: 어두운 실내·야간·기본값). 라이트는 사용자가 고르고 `localStorage`에 남긴다. `/hud`는 항상 다크다.

## 3. 다듬은 점

- **유리 질감:** 위쪽 안쪽 하이라이트 1px, 채도 140%, 아래로 퍼지는 그림자를 더했다. 라이트에서는 흰 외곽선과 0.5px 갈색 머리선을 겹쳐 밝은 배경에서도 테두리가 보인다.
- **상태 점:** 점 둘레에 같은 색 22% 후광을 둬서 작은 점도 색이 읽힌다. 보류는 속이 빈 고리다.
- **카운터 오브:** 2.5px 고리 + 7px 연한 바깥 띠 + 상태색 빛번짐(다크 38%, 라이트 18%). 숫자는 고정폭이라 0→2로 바뀌어도 흔들리지 않는다.
- **대상 프레임:** 모서리의 Clay 점을 빼고, 위에 물체 이름표(예: "바나나")를 붙였다. 점이 차단 빨강과 구분되지 않았고, 이름표가 정보를 하나 더 준다.
- **로그 카드:** 분기 코드(2a~2d, raw)를 작은 태그로 붙였다(F6 요구). 가림 방식을 썸네일 표시로 구분한다: 2b는 모자이크 칩, 2c는 위 40% 가림, 2d는 점선 빈칸.
- **성능 대비:** `data-glass="solid"`로 흐림을 끄고 유리를 거의 불투명하게 바꿀 수 있다. iPhone에서 카메라 위 흐림과 MediaPipe GPU 추론을 함께 돌린 비용은 아직 재지 않았다.
- **움직임 줄이기:** `prefers-reduced-motion`이면 점멸과 알림 움직임을 끈다. 알림은 3초 뒤 그냥 사라진다.

## 4. 시안과 명세가 부딪히는 곳

| # | 시안 | 명세 | 처리 |
| --- | --- | --- | --- |
| 1 | 이름 "LensGate OS", 브랜드 캡슐 "LensGate" | 제품명 famelet 확정 | `APP_NAME`(famelet)을 쓴다. "OS"는 붙이지 않았다. 필요하면 알려 주면 된다 |
| 2 | 한 화면에 로그 카드 3장, 사람 박스, 알림까지 함께 있음 | HUD는 요소 5개 이내: 장면·입력·대상 위치·카운터·결과(PRD HUD 규칙) | HUD 안에는 다섯 개만 둔다. 로그는 휴대폰 하단 시트, 데스크톱 오른쪽 탭으로 옮긴다. 시안에 없던 **입력 표시**("후면 카메라"/"녹화 영상")를 더했다 |
| 3 | 결과 15~16px, 장면 22px, 보조 11~12px | `/hud` 600×600에서 본문 24px 이상, 카운터 40px 이상 | `/hud`에만 큰 글자 묶음(§2 오른쪽 열)을 쓴다. 휴대폰·데스크톱은 시안 크기를 쓰되 보조 설명은 12px 아래로 내리지 않는다 |
| 4 | 유리·흐림·라이트 모드 | `/hud`는 검은 배경(가산형 디스플레이에서 투명) | `[data-view='hud']`는 유리·흐림 없이 검은 바탕에 외곽선만 둔다. 라이트로 바꾸지 않는다 |
| 5 | 빨간 오브 "4 · 차단 시도" | 카운터 숫자는 "앱에 반영된 사람 수"(PRD: HUD의 주인공). 차단 횟수는 Counter에 정의가 없다 | 오브 숫자는 항상 사람 수다. 차단은 오브 옆 빨간 배지("차단 4")로 따로 보인다. 숫자는 세션 동안의 violation 로그 수인데, 로그가 100건에서 밀려나면 줄어든다. 줄면 안 된다면 Counter에 `violations`를 더해야 한다(core 변경, 미결) |
| 6 | 전달 알림 토스트만 있음 | 전달 신호의 기본은 HUD 테두리 300ms 점멸 + "전달됨"이고, 소리·진동은 보조(F9). 보류는 소리 없이 하단에 "보류"만 | 테두리 점멸(`fm-flash`)을 기본으로 두고 토스트는 휴대폰·데스크톱에서만 덧붙인다. `/hud`에는 토스트를 띄우지 않는다 |
| 7 | 사람 박스 + "사람 · 전달 안 함" | HUD 요소에 사람 박스가 없다. 사람이 조각과 겹치면 가린 채 **전달된다**(2b·2c) | "전달 안 함"은 틀린 말이 될 수 있어 쓰지 않는다. 대신 "화면 속 N명"(PRD 카운터 정의)을 작은 캡슐로 둔다. 사람 박스를 그리려면 `LiveObservation`에 박스 목록이 필요하다(지금은 수만 있음, core 변경) |
| 8 | Clay = 로고·포커스 점 | 색은 의미에만(PRD) | Clay는 HUD 밖 브랜드 점에만 쓴다. 차단 빨강과의 밝기 대비가 1.07(다크)·1.19(라이트)라 눈으로 구분되지 않는다 |
| 9 | 로그 카드: 썸네일·크기·원본 대비 비율 | F6: 분기(2a~2d), 가린 얼굴 수, 처리 위치, 수신 미확인 표시도 필요 | 카드에 분기 태그, "얼굴 N개 가림", "이 기기에서 가림", "수신 미확인"을 넣었다. 2c(머리 가림) 카드를 새로 그렸다 |
| 10 | 카운터 "0" + "앱에 반영된 사람 · 보호됨" | PRD 문구 "현재 앱에 반영된 사람 수: 0명", 데모 대사 "주황 2명" | 캡션에 "0명"을 넣었다. 오브 안 숫자는 시안대로 단위 없이 둔다 |
| 11 | 사용자 요청 "다크모드/기본모드" | 시안: 다크가 기본값, 라이트는 수동 | 시안을 따라 다크를 기본으로 했다. "기본모드"를 라이트로 이해했다. 다르면 알려 주면 된다 |

## 5. 측정해 보니 바꾼 것 (대비, WCAG)

`blur`가 없다고 보고, 유리 투명도로 섞은 바탕과 글자의 대비를 쟀다. 실제로는 흐림이 배경을 평균 내므로 조금 나아진다.

| 경우 | Text | Sub | 결론 |
| --- | --- | --- | --- |
| 다크 74%, 어두운 장면 | 16.8 | 7.3 | 충분 |
| 다크 74%, 흰 접시 위 | 8.2 | 3.6 | Sub는 작은 글자 기준(4.5) 미달. 흰 물체 위 캡슐에는 Sub를 쓰지 않는다 |
| 다크 32%, 흰 접시 위 | 2.4 | 1.1 | **글자 불가.** 얇게는 장식에만 |
| 라이트 74%, 밝은 장면 | 18.4 | 7.4 | 충분 |
| 라이트 74%, 어두운 그림자 위 | 11.9 | 4.8 | 충분. 단 Safe 3.0·Exposed 3.1은 큰 숫자(3:1)만 겨우 통과 |
| 라이트 32%, 어두운 그림자 위 | 4.2 | 1.7 | **글자 불가** |

상태색 글자는 오브의 큰 숫자에만 쓰고, 작은 글자는 Text 색에 상태 점을 붙인다.

## 6. 시안에 없는 화면과 상태 (트랙 C가 이 토큰으로 만든다)

- 바깥 표시 `/outward`: "지금 당신의 얼굴을 본 앱: N개"를 화면 높이 30% 이상으로. 0은 초록, 1 이상은 주황, 메시지가 낡으면 회색 "연결 끊김"(F15, IF-07)
- 확인 화면: "이 플러그인이 본 것은 이 사진 N장뿐" + 썸네일 그리드, "외 k장(썸네일 해제됨)"(F12)
- 매니페스트 편집기: JSON, 검증 오류 목록, 적용 중 상태, `stopped`이면 "다시 켜기"(F11·F14)
- 처리량 패널과 "기업 서버 재검사: 미구현" 비활성 안내(F16·F19)
- 발표자 컨트롤: 비교 모드 스위치, 전달 일시 정지, 새 세션 시작(F17·F20)
- 시작 화면: 시작 버튼(오디오 잠금 해제·카메라 권한), 모델 받는 중 진행 표시. iPhone 첫 추론이 11~14초라 기다리는 동안 보여 줄 화면이 필요하다
- 실패 상태: 카메라 거부 → 녹화 영상으로 전환 안내(F1·F10), 판정 엔진 실패 → 전달 정지 표시, 플러그인 `stopped`·`terminated`
- 입력 선택 드롭다운(F10), 데스크톱 오른쪽 탭 머리(로그 / 확인 화면 / 매니페스트 / 처리량)

## 7. 쓰는 법

- `src/main.tsx`가 `theme.css`를 불러오고 저장된 테마를 적용한다. 전환 버튼은 `applyTheme('light' | 'dark')`.
- `/hud` 화면의 최상위 요소에 `data-view="hud"`를 붙이고 `applyTheme('dark', false)`를 부른다.
- 상태는 `data-tone="safe|exposed|blocked|hold"`, 재질은 `fm-glass` + `fm-glass--panel`.
- 폰트는 CDN 없이 `pretendard`(가변 동적 서브셋)와 `@fontsource/noto-serif-kr`(400) 패키지에서 번들된다. 쓰는 글자 범위의 파일만 내려받는다.
